> **参赛赛道：** 2026年广东省“数智新技艺”作品遴选活动 —— 自主研发应用赛道

## 项目简介 (Introduction)

在高校网络思政教育中，通用大语言模型（LLM）常面临**“知识幻觉（胡编乱造）”**与**“政治用语不规范”**的痛点。为了解决这一问题，本项目自主研发了一款**专为高校思政场景设计的 RAG（检索增强生成）智能伴读系统**。

系统支持一键上传权威思政文献（如《二十大报告》、《毛泽东选集》节选、党史资料等），通过长文本切片、向量化检索与大模型深度融合。**系统绝不直接代写论文，而是作为学生的“理论伴读”，严格基于用户上传的原文进行问答，确保知识输出的 100% 溯源与绝对严谨。**

## 核心功能 (Core Features)

*   **内容安全护栏：** 内置思政领域专属过滤机制，自动拒绝非思政类文献与无关提问，确保应用场景的纯粹性与安全性。
*   **拒绝 AI 幻觉：** 依托 RAG 架构，所有回答均严格锚定上传的文献原文，严禁模型凭空捏造政治术语或历史事件。
*   **精准寻根溯源：** 每一句回答均附带原文出处提示，帮助大学生在写思政论文或党课作业时进行严谨、规范的学术引用。
*   **极速响应体验：** 基于 Streamlit 构建轻量级 Web 前端，无需下载安装，跨平台（PC/移动端）扫码即用。
